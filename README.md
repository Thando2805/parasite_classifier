# Parasite Classifier 

A lightweight computer vision application powered by a custom **YOLOv8** model and a **FastAPI** backend, designed for rapid parasite detection and classification. 

---

##  Tech Stack
* **Backend:** Python, FastAPI, Uvicorn, OpenCV
* **Model:** Ultralytics YOLOv8
* **Frontend:** HTML, CSS, JavaScript interface
* **Deployment:** Docker, Render Cloud Platform
